# Meu Financeiro UNIP - ADS

Dashboard feito em JavaScript puro para controlar a mensalidade da faculdade de Análise e Desenvolvimento de Sistemas na UNIP.

**Live Demo:** (vamos colocar o link da Vercel aqui depois)

### Funcionalidades
- Calcula quanto sobra do salário após a mensalidade
- Mostra quantos meses de faculdade já estão pagos
- Barra de progresso do curso (30 meses)
- Gráfico de gastos com Chart.js
- Salva dados no LocalStorage

### Tecnologias
- HTML, JavaScript, Tailwind CSS, Chart.js

Feito por um aluno da UNIP Anchieta que trabalha em gráfica e está migrando pra TI.
